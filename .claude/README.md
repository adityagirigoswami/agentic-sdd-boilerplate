# `.claude/` — Claude Code adapter

| Path | Source of truth | Edit? |
|---|---|---|
| `skills/`, `agents/`, `commands/` | `.agents/{skills,roles,workflows}` | **No** — generated by `make sync-agents` |
| `hooks/` | here | yes |
| `settings.json` | here (team) | yes |
| `settings.local.json` | here (you; gitignored) | yes — copy from `.example` |

Claude-only skills/agents/commands you add by hand (no `GENERATED` marker) are never touched by the sync.

## Hooks

| Event | Script | Does |
|---|---|---|
| `SessionStart` | `session-start.sh` | Injects phase, 🟡/⛔ features, active focus, recent lessons, git state |
| `PreToolUse` | `guard-secrets.sh` | Blocks Read/Edit/Write/Bash touching `.env*`, `*.pem`, `*.key`, `*-key.json` (not `.example`) |
| `Stop` | `docs-guard.sh` | Code changed but `docs/` untouched → asks Claude once to walk the docs-sync matrix (`DOCS_GUARD=0` disables) |

Add a `PostToolUse` hook (matcher `Edit|Write`) running your formatter/linter once the stack exists.
