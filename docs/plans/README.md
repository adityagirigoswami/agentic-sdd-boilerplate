# Plans

Dated, step-by-step implementation plans for work spanning more than ~1 day:
`YYYY-MM-DD-<feature>.md`. Each task names files and how to verify it. Plans are **working docs** —
link them from the feature's `status.md`; once the feature is ✅, the plan may go stale (the truth is in
`design.md` + `guide.md`).
